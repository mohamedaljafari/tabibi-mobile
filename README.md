# طبيبي — تطبيق المريض

تطبيق الهاتف الخاص بالمرضى في منصة **طبيبي** لتقديم خدمات الرعاية الصحية المنزلية في ليبيا. يتيح التطبيق للمريض إنشاء حسابه وإدارة ملفه الطبي وعناوينه، والبحث عن مقدمي الخدمات الصحية حسب التخصص (أطباء، تمريض، رعاية كبار السن والعلاج الطبيعي، صحة نفسية، تغذية وصحة وجمال، مختبرات، صيدليات، طب بيطري)، وطلب الخدمة والحجز والدفع، ثم متابعة الطلبات والدردشة مع مقدم الخدمة بعد القبول وتقييم الخدمة.

## نظرة عامة على النظام

يتكون النظام من ثلاثة أجزاء مرتبطة معًا عبر مخزن بيانات محلي مشترك على الجهاز:

| الجزء | المستودع | الوظيفة |
|-------|----------|---------|
| تطبيق المريض (هذا المستودع) | [tabibi-mobile](https://github.com/mohamedaljafari/tabibi-mobile) | البحث عن مقدمي الخدمات، الطلب، الدفع، الدردشة، المحفظة، الملف الطبي |
| تطبيق مقدم الخدمة | [tabibi-partner](https://github.com/mohamedaljafari/tabibi-partner) | استقبال الطلبات، قبولها ورفضها، إدارة الخدمات والمواعيد، الدردشة، الأرباح |
| لوحة تحكم الإدارة | داخل تطبيق المريض عبر المسار `/admin` | إدارة الحسابات والإعلانات والخدمات والطلبات والسجلات الطبية والمحفظات |

## ميزات التطبيق

يتضمن التطبيق مجموعة من الميزات الأساسية التي تغطي رحلة المريض كاملة. يبدأ المستخدم بإنشاء حسابه (الاسم ورقم الهاتف وكلمة المرور) ثم استكمال بياناته الشخصية وعناوينه وملفه الطبي وملفات أفراد العائلة. تعرض الصفحة الرئيسية بنرات إعلانية (تُدار من لوحة التحكم) وشبكة أيقونات الخدمات الرئيسية التي تقود كل منها إلى صفحات بحث مخصصة حسب التخصص مع خيارات الفلترة والفرز (الأقرب، الأعلى تقييمًا، الأعلى والأقل سعرًا).

تشمل الميزات الأخرى نظام الطلبات مع إشعارات فورية، ونظام الدفع (نقدي يُدفع بعد انتهاء الخدمة، أو إلكتروني يظهر فقط بعد قبول مقدم الخدمة للطلب)، والدردشة النصية مع إمكانية إرفاق الصور والتقارير الطبية (PDF)، ونظام التقييم بالنجوم مع تعليق نصي، والمحفظة المحاسبية التي ترصد عمليات الشحن والدفع والاسترداد، والملف الطبي الذي يوثق العمليات والخدمات مع إمكانية منح مقدم الخدمة صلاحية الاطلاع عليه أو إلغاؤها.

## هيكل المشروع

```
tabibi-mobile/
├── app/                 # الشاشات (Expo Router)
│   ├── (tabs)/          # التبويبات الرئيسية (الرئيسية، طلباتي، المحفظة، حسابي)
│   ├── (service)/       # مسارات الخدمات (طبيب، تمريض، نفسية، تغذية، مختبر...)
│   ├── chat.tsx         # الدردشة مع مقدم الخدمة
│   ├── payment.tsx      # الدفع (نقدي/إلكتروني)
│   ├── admin.tsx        # لوحة تحكم الإدارة
│   └── setup.tsx        # استكمال بيانات الحساب والملف الطبي
├── lib/                 # المكتبات المنطقية المشتركة
│   ├── chat.ts          # الدردشة والمرفقات
│   ├── wallets.ts       # المحفظة المحاسبية
│   ├── service-requests.ts
│   ├── notifications.ts
│   ├── ratings.ts
│   └── medical-records.ts
├── components/          # المكونات المشتركة (مثل chat-attachment-bar)
├── constants/           # الثوابت والمعرفات
├── tests/               # اختبارات Vitest (أكثر من 150 اختبارًا)
└── .github/workflows/   # عمليات GitHub Actions (CI)
```

## التثبيت والتشغيل

يتطلب المشروع Node.js 22 وpnpm 9. أنشئ المستودع محليًا ثم ثبّت الحزم وشغّل خادم التطوير:

```bash
git clone https://github.com/mohamedaljafari/tabibi-mobile.git
cd tabibi-mobile
pnpm install
pnpm dev
```

يفتح خادم التطوير معاينة ويب على المنفذ 8081. لتجربة التطبيق على هاتفك الفعلي، امسح رمز QR الذي يولّده Expo عبر تطبيق **Expo Go** (متاح في App Store وGoogle Play).

```bash
pnpm android   # تشغيل على محاكي Android
pnpm ios       # تشغيل على محاكي iOS
pnpm test      # تشغيل الاختبارات
pnpm check     # التحقق من TypeScript
```

## التخزين المحلي المشترك

يعتمد التطبيقان على مفاتيح AsyncStorage موحدة ليظهرا كأنهما متصلان بخلفية واحدة على الجهاز نفسه، ومن أبرزها:

| المفتاح | المحتوى |
|---------|---------|
| `provider_accounts_v1` | حسابات مقدمي الخدمات وحالاتها |
| `service_requests_v1` | الطلبات المشتركة بين الطرفين |
| `chat_threads_v1` / `chat_messages_v1` | المحادثات ورسائلها ومرفقاتها |
| `wallets_v1` | قيود المحفظة المحاسبية |
| `ads_v1` | الإعلانات والبنرات المدارة من لوحة التحكم |
| `ratings_v1` | التقييمات |
| `provider_chat_threads_v1` | محادثات مقدم الخدمة |

## بناء تطبيق الجوال ونشره

يُنشأ ملف APK من تطبيق Expo Go أو عبر زر **Publish** في واجهة المشروع على منصة Manus، والتي تبني النسخة النهائية وتولّد ملف APK قابل للتثبيت على Android. يُفضَّل استخدام هذه الآلية بدل البناء اليدوي في بيئة التطوير لتجنب استهلاك الموارد.
